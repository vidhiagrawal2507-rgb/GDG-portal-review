GDG AITR Portal Review & Suggestions

Website Link

Reviewed Website: https://gdgocaitr.vercel.app/

What I Checked

  • Broken links: Tested all 18 primary internal routes and external community links (Home, Announcements, Team, About, Gallery, Contact, Events, Event Registration, Login, Signup, Recruitment, Guidelines, Privacy, Terms) for 404 or dead ends.
  • Text alignment: Inspected hero banners, heading hierarchy, paragraph alignments, and card labels on both desktop and mobile viewports.
  • Mobile layout: Inspected mobile viewport scaling, hamburger menu visibility, horizontal overflow, and touch usability across multiple phone widths (375px, 390px, 480px, 768px).
  • Visual glitches: Checked for unwanted element clipping, off-screen overflow, card shadow consistency, and image rendering.

Findings

Detailed breakdown of observations and issues found across all checked categories:

1. Broken Links

No major issue found

All 18 tested routes (/announcements, /team, /about, /gallery, /contact, /events, /login, /signup, etc.) returned HTTP 200 status codes with no broken 404 pages. The only minor item noted was on the Contact page, where the physical location item uses an empty anchor target (href="#") rather than a link to Google Maps.

2. Mobile Layout

Issue found

On standard smartphone screens below 420px (such as iPhone SE at 375px and iPhone 12/13/14 at 390px), the top hero pill badge ("Google Developer Groups on Campus • AITR Indore") and heading container exceed the screen width. This causes horizontal overflow, which pushes the mobile hamburger menu toggle button off-screen to the right.

3. Text Alignment

Issue found

On desktop, text alignment is balanced, clean, and properly centered. However, on mobile devices under 420px, the horizontal overflow causes hero titles, subtitle text, and card labels to appear cut off along the right display edge.

4. Visual Glitches

Issue found

Desktop displays without visual glitches. On mobile viewports under 420px, visual clipping occurs along the right edge of cards, buttons, and the top Google 4-color stripe due to the horizontal layout overflow.

5. Overall Navigation & Usability

Issue found

"Events" is a flagship activity of any GDG chapter, but it is currently absent from the main desktop navigation bar (which lists Home, Announcements, Team, About, Gallery, Contact). Users can only access Events via the hero button or footer links. Additionally, the mobile menu button is difficult to reach on small phones because it gets pushed outside the viewport.

Suggestions

  • Better mobile responsiveness: Fix horizontal overflow on screens under 420px by adding max-width: 100% and flex-wrap: wrap to the hero pill badge, and adjusting the hero heading font size minimum clamp from 36px to 26px so the hamburger menu and text stay fully visible on all mobile phones.
  • Improved text spacing and alignment: Apply responsive padding (e.g., padding: 0 16px) to mobile content containers to prevent text from overflowing or touching screen boundaries on narrow displays.
  • Clearer navigation: Add an "Events" link directly to the top desktop navigation bar so users can quickly discover workshops and study jams; keep the mobile hamburger button pinned inside the viewport at all times.
  • Better visual consistency: Replace the placeholder href="#" on the Contact page location card with an actual Google Maps URL for Acropolis Institute of Technology and Research (AITR), Indore.

Desktop Review

Tested on desktop resolutions (1280x800 and 1920x1080). The website delivers a clean, modern developer community presentation. The signature Google 4-color top bar (Blue, Red, Yellow, Green) sets a branded tone, followed by an organized navigation bar, high-impact hero banner, and clean stats cards (1250+ active members, 25+ events, 450+ cloud badges, 8+ hackathons). Workshop listings, mission points, and chapter lead profiles (Dr. Kamal K. Sethi, Dr. Narendra Pal Singh Rathore, Dr. Priyanka Jangde) are arranged in well-proportioned multi-column grids. Page load speeds are fast and text is crisp. The main usability improvement needed is adding "Events" to the top navigation header.

Mobile Review

Tested across mobile viewports (375px iPhone SE, 390px iPhone 12/13/14, 480px, and 768px). On larger mobile screens (480px and wider), the layout stacks cleanly and the hamburger menu works smoothly. However, on standard smartphones under 420px width, the hero pill badge and header container cause horizontal overflow. This clips text along the right screen margin and pushes the hamburger toggle off-screen, making navigation hard to access without horizontal scrolling. Allowing the badge to wrap and tuning container widths will make the mobile experience fully responsive and accessible.
